# 公開前の設定

## 多言語フォルダ（v35）

`en`、`ko`、`es`、`zh-cn`、`pt-br` フォルダも、ルートのHTML・PHP・`assets`と同じ階層関係を保ったままアップロードしてください。`sitemap.xml` と `robots.txt` も上書きします。

## 1. メールアドレス

ロリポップに用意されている `info@exifframe.net` を、お問い合わせの受信先と自動返信の送信元に使用します。

`info@exifframe.net` からGmailへ転送すると、日常の確認が簡単です。返信時に個人用Gmailを表示したくない場合は、独自ドメインのメールとして返信できるように設定してください。

## 2. HTTPS

ロリポップの無料独自SSLを有効にし、`https://exifframe.net/` で公開してください。

同梱の `.htaccess` はHTTPS転送とセキュリティヘッダーを設定します。アップロード後に500エラーが発生する場合は、ロリポップの設定とサポート情報を確認し、対応していない行を一時的にコメントアウトしてください。

## 3. メール認証

ロリポップのメール設定でSPF・DKIMを有効にし、可能であればDMARCも設定してください。Gmailなどへテスト送信し、迷惑メール扱いにならないことを確認します。

## 4. フォームの動作確認

公開後、実際にフォームからテスト送信し、次を確認してください。

- `info@exifframe.net` に届く
- 入力者へ自動返信が届く
- 迷惑メールフォルダへ分類されない
- 返信ボタンで入力者のアドレスが宛先になる

## 5. 初めての方向けページの作例写真

紹介ページは `https://exifframe.net/start.html` です。作例写真は `assets/images/top/` に追加し、`assets/js/top-photos.js` に登録してください。詳しくは同フォルダの `README.txt` を参照してください。
